# Codex Stage 2 Automation Lab

This public repository is a small, generic test fixture for a complete GitHub workflow:

- repository and branch creation;
- issue and pull-request lifecycle;
- squash merge verification;
- GitHub Pages deployment;
- independent shallow-clone verification.

The published page contains no personal, desktop, or third-party account data.

The repository root is a self-contained static site designed for GitHub Pages.
